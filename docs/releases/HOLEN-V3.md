# HOLEN V3.3.1

> Native Android downloads, with a cleaner first impression.

HOLEN V3.3.1 is the current V3 Android build. The installed app name is simply **HOLEN**.

## What's new

- The launcher and installer label are explicitly `HOLEN`.
- The welcome animation ends with a tappable **Made by @yashas.vm** credit that opens the creator's GitHub profile.
- The project README and V3 release presentation now center the Android install path.

## Highlights

| Area | What it does |
|---|---|
| **Links in** | Paste an HTTPS URL or share it to **Download with HOLEN**. |
| **Formats out** | Choose MP4, M4A, MP3, or the original direct file where available. |
| **Runs in background** | Shows notifications and supports playlists, retry, resume, and cancel. |
| **Saves where you choose** | Uses Android's system folder picker and preserves its permission. |
| **Stays private** | No analytics or telemetry; optional `cookies.txt` is private on-device data. |

## Install

Android 10 or newer is required. Install the ARM64 APK on modern phones, including the Galaxy S24 Ultra:

- [Download HOLEN-v3.3.1-arm64-debug.apk](https://github.com/YashasVM/HOLEN/releases/download/V3/HOLEN-v3.3.1-arm64-debug.apk)
- [Verify SHA256SUMS-V3](https://github.com/YashasVM/HOLEN/releases/download/V3/SHA256SUMS-V3)

## Responsible use

Save only files and media you own or are authorized to download. HOLEN cannot bypass DRM or other access controls, and supported source availability can change.
