# Changelog

## 3.3.0 — HOLEN V3

- Public Android-first release with installed app name `HOLEN`.
- Share-to-HOLEN workflow, direct-file and supported-media downloads, format
  selection, playlists, background notifications, and resumable controls.
- Advanced private on-device `cookies.txt` support for authorized media-page
  access.
- Updated licensing guidance: HOLEN Android is GPL-3.0; HOLEN OSS and the
  server editions are MIT-licensed subject to dependency licenses.
- Signed ARM64, ARMv7, and universal GitHub Release assets with SHA-256
  checksums.

See [HOLEN V3 release notes](docs/releases/HOLEN-V3.md) for details.
