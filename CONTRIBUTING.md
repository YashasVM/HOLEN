# Contributing

Keep contributions focused, dependency-light, and safe for self-hosting.

1. Create a branch for one cohesive change.
2. Run the checks from the README before opening a pull request.
3. Do not commit `.env` files, cookies, databases, downloaded media, or credentials.
4. Describe any new environment variable in `.env.example` and the README.

For security-sensitive issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
